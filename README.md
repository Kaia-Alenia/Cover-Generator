# Alenia Studios | Cover Generator 🎨

[![Platform: Web](https://img.shields.io/badge/Platform-Web-blueviolet.svg)](#)
[![Made with: HTML2Canvas](https://img.shields.io/badge/Made%20with-HTML2Canvas-blue.svg)](https://html2canvas.hertzen.com/)

A minimalist, high-performance web tool designed to create professional covers for game assets, music packs, and indie resources. Originally developed as an internal utility for **Alenia Studios** to standardize asset presentation.

---

## ✨ Features

*   **Adaptive Resolutions:** Built-in presets for popular platforms.
*   **Real-time Preview:** See every color and text change instantly.
*   **High-DPI Export:** Automatic $2\times$ scaling for crisp, professional PNG files.
*   **Zero Dependencies:** Runs entirely in the browser using a single HTML file.

## 📐 Supported Formats

| Format | Resolution | Best Use Case |
| :--- | :--- | :--- |
| **Standard Pack** | $1000 \times 800$ px | Itch.io / GameDev Market |
| **Ci-en Banner** | $1280 \times 720$ px | Japanese Dev Blogs / Banners |
| **Full HD** | $1920 \times 1080$ px | Wallpapers / YouTube Thumbnails |
| **Square** | $1000 \times 1000$ px | Bandcamp / Soundtrack Art |

---

## 🚀 Quick Start

1.  **Host it:** Upload `index.html` to a GitHub repository.
2.  **Deploy:** Go to `Settings > Pages` and select the `main` branch.
3.  **Create:** Open your site URL, customize your text and brand colors, and hit **Export**.
